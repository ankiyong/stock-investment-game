# 마켓 리그 — 주식투자 게임

참여 조 수를 1~20조로 정할 수 있는 수업용 가상 주식투자 게임입니다.

## 실행

https://ankiyong.github.io/stock-investment-game/

또는 index.html 파일을 브라우저에서 직접 엽니다.

## 기능

- 조 이름, 시작 자금, 라운드 수 설정
- 가상 6개 종목의 매수·매도와 뉴스 기반 주가 변동
- 조별 거래 완료, 거래 취소, 토론 타이머
- 최종 순위, 자산 추이, 결과 CSV 다운로드
- 같은 브라우저에서 자동 저장 및 이어 하기

진행자 한 기기에서 각 조의 결정을 입력하는 방식입니다. 여러 기기 사이에 게임 진행 상태가 자동 동기화되지는 않습니다.

## 배포

GitHub Pages는 저장소 기본 브랜치의 루트 폴더를 게시합니다. 게임을 수정하려면 index.html을 업데이트합니다. 외부 라이브러리나 빌드 단계는 없습니다.
